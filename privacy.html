Privacy Policy

Work on Another Video — Last updated September 3, 2026

In short: Work on Another Video does not collect, transmit, sell, or share your personal data. The extension only checks YouTube Studio URLs locally in your browser so it can determine which Studio section is open.

Work on Another Video is a Chrome extension designed to help YouTube creators avoid repeatedly checking YouTube Studio analytics by replacing selected YouTube Studio pages with a reminder to work on another video.

Information the extension accesses

The extension locally examines the URL of pages on studio.youtube.com to determine whether the user is viewing Analytics, Dashboard, Community, or another YouTube Studio section.

The extension also stores the user's preferences for whether the Dashboard and Community pages should be blocked using Chrome's storage API.

Data collection and transmission

Work on Another Video does not collect, transmit, sell, or share user data with the developer or any third party.

YouTube Studio URLs are processed locally in the user's browser and are not recorded or transmitted to the developer.

The extension does not collect YouTube analytics data, video information, account information, names, email addresses, personal communications, authentication information, or YouTube Studio page content.

Stored preferences

The extension stores only the user's settings for optional Dashboard and Community blocking. These settings are used solely to provide the extension's requested functionality.

Third parties

No user data is shared with third parties. The extension contains no advertising, analytics, tracking services, or remotely hosted executable code.

Chrome Web Store Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes to this policy

If the extension's data practices change, this privacy policy will be updated to reflect those changes.
